1. 서비스 목적 (Service Purpose) 실시간 나스닥 시장 데이터와 관련 뉴스(맥락)를 완벽하게 통합하여 제공합니다. 사용자가 화면을 전환하지 않고도 주가 변동(Price Action)과 그 원인(뉴스/이슈)을 즉시 연결하여 파악하고 신속하게 투자 결정을 내리도록 지원합니다.

2. 서비스 타깃 (Target Audience): 미국 기술주 섹터에 집중하며, 빠른 정보 습득을 중요시하고 뉴스 기반의 매매 전략을 적극적으로 사용하는 투자자들.

3. 핵심 가치 (Core Values)

맥락적 통찰 (Contextual Insight): "주가가 얼마인지"와 "왜 변동했는지"를 알 수 있도록 차트 옆에 관련 뉴스를 배치하여 인과관계를 제공합니다.

끊김 없는 흐름 (Seamless Flow): 메인 피드를 벗어나지 않고도 스크롤 탐색과 모달(Modal) 팝업을 통해 차트를 심층 분석할 수 있는 매끄러운 UX를 구현합니다.

데이터 명확성 (Data Clarity): 평단가, 현재가, 실시간 손익(P/L) 등 포트폴리오 지표를 직관적으로 시각화하여 자산 현황을 한눈에 이해하게 합니다.
