# MeJang_price 📈

미국 나스닥 시장의 실시간 데이터와 뉴스, 그리고 유명 투자자 스타일의 포트폴리오 시뮬레이션을 제공하는 투자 학습 플랫폼

## 서비스 목적 (Service Purpose)

실시간 나스닥 시장 데이터와 관련 뉴스(맥락)를 완벽하게 통합하여 제공합니다. 사용자가 화면을 전환하지 않고도 주가 변동(Price Action)과 그 원인(뉴스/이슈)을 즉시 연결하여 파악하고 신속하게 투자 결정을 내리도록 지원합니다.

또한, **워렌 버핏, 캐시 우드 등 세계적인 투자 거장들의 포트폴리오 스타일을 실제 과거 데이터로 시뮬레이션**하여, 각 투자 전략이 실제로 어떤 성과를 냈는지 확인할 수 있습니다. 이를 통해 투자 초보자도 검증된 투자 전략을 학습하고, 자신에게 맞는 투자 스타일을 찾을 수 있습니다.

## 서비스 타깃 (Target Audience)

- **주요 타깃**: 미국 기술주 섹터에 집중하며, 빠른 정보 습득을 중요시하고 뉴스 기반의 매매 전략을 적극적으로 사용하는 투자자들
- **추가 타깃**: 투자 전략을 학습하고자 하는 초보 투자자 및 다양한 포트폴리오 전략의 실제 성과를 비교 분석하고 싶은 중급 투자자

## 핵심 가치 (Core Values)

### 1. 맥락적 통찰 (Contextual Insight)
"주가가 얼마인지"와 "왜 변동했는지"를 알 수 있도록 차트 옆에 관련 뉴스를 배치하여 인과관계를 제공합니다.

### 2. 끊김 없는 흐름 (Seamless Flow)
메인 피드를 벗어나지 않고도 스크롤 탐색과 모달(Modal) 팝업을 통해 차트를 심층 분석할 수 있는 매끄러운 UX를 구현합니다.

### 3. 데이터 명확성 (Data Clarity)
평단가, 현재가, 실시간 손익(P/L) 등 포트폴리오 지표를 직관적으로 시각화하여 자산 현황을 한눈에 이해하게 합니다.

### 4. 검증된 투자 전략 학습 (Proven Strategy Learning)
워렌 버핏, 캐시 우드 등 세계적인 투자 거장들의 포트폴리오 구성을 실제 과거 데이터로 시뮬레이션하여, 각 전략의 실제 성과를 확인할 수 있습니다. 사용자는 다음을 학습할 수 있습니다:
- **빅테크 포트폴리오**: FAANG 중심의 성장주 투자 전략
- **워렌 버핏 스타일**: 가치투자 중심의 안정적인 장기 투자 전략
- **ARK Innovation 스타일 (캐시 우드)**: 혁신 기술 기업 중심의 공격적 성장 전략
- **배당왕 포트폴리오**: 안정적인 배당 수익 중심의 보수적 전략

각 포트폴리오의 종목별 수익률, 시간대별 가치 변화를 그래프와 상세 데이터로 제공하여, 과거 특정 시점에 투자했다면 현재 어떤 성과를 냈을지 명확하게 확인할 수 있습니다.




## 주요 기능

### 📊 실시간 시장 데이터
- 나스닥 Top 100 종목 실시간 조회
- TradingView 차트 통합

### 📰 통합 뉴스 피드
- 주요 종목별 관련 뉴스 제공
- 주가 변동과 뉴스의 연결성 분석

### 💼 포트폴리오 시뮬레이션
- 4가지 유명 투자 전략 포트폴리오 제공
- 과거 데이터 기반 수익률 계산
- 종목별 상세 수익률 분석
- 월별 포트폴리오 가치 변화 차트

### 🔐 사용자 인증
- Supabase 기반 안전한 인증 시스템
- 선택적 로그인 (일부 기능은 로그인 없이 이용 가능)

- **Styling**: styled-components
- **Backend**: FastAPI, Supabase
